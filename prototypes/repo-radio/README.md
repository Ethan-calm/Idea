# 📻 Repo Radio

커밋 기록을 로파이 음악으로 연주하는 브라우저 앱. `index.html` 하나로, 설치나 서버 없이 바로 열면 됩니다.

**소스 3가지:** 데모 팀(중간에 장애 사고 포함) · GitHub 공개 레포(최근 60커밋) · `git log` 붙여넣기(변경 줄 수까지 반영)

```bash
git log -60 --shortstat --pretty=format:'%h|%an|%at|%s'
```

**소리 규칙:** 사람마다 다른 악기와 음높이 · feat는 올라가는 아르페지오 · fix는 으뜸음으로 해결 · test는 종소리 · docs는 작고 높은 음 · revert/hotfix/broken은 2마디 단조로 바뀌고 화면도 흐려짐 · 300줄 넘는 변경은 베이스 드롭 · 커밋 사이 실제 시간 간격이 리듬이 됨
