커밋이 음표가 되는 로파이 라디오. 팀이 일하는 소리를 들어보세요.

가상의 4인 팀이 하루 동안 남긴 커밋 40개를 연주해요. 중간에 사고가 하나 터집니다 🔥

최근 커밋 60개를 불러와요 (로그인 없이 시간당 60회 제한).

레포에서 이 명령 결과를 붙여넣으면 변경 줄 수까지 반영돼요:
git log -60 --shortstat --pretty=format:'%h|%an|%at|%s'

방송 기록

    무엇이 어떤 소리?

    • 🎹 커밋 = 멜로디 한 음 (사람마다 다른 악기·높이)
    • ✨ feat/add = 올라가는 아르페지오
    • 🩹 fix = 코드의 으뜸음으로 '해결'
    • 🔔 test = 맑은 종소리
    • 📝 docs = 작고 높은 음
    • 🔥 revert/hotfix/broken = 2마디 단조로 전조
    • 💥 300줄 넘는 변경 = 베이스 드롭
    • 💿 배경: 로파이 드럼 + 코드 패드 + LP 잡음
