# 🏝️ Agent Survivor

같은 과제를 성격이 다른 에이전트 5명이 만들고, **내가 블라인드로 투표**하면 꼴찌는 탈락하고 1·2등이 새 참가자를 낳습니다. 시즌이 진행될수록 참가자들이 **내 취향 쪽으로 진화**해요.

```
init ─▶ round ─▶ gallery.html에서 블라인드 투표 ─▶ vote ─▶ 정체 공개 · 탈락 · 탄생 ─┐
          ▲                                                                       │
          └───────────────────────────────────────────────────────────────────────┘
```

## 해보기 (토큰 없이)
```bash
python3 survivor.py init "할 일 관리 앱을 만들어줘"
python3 survivor.py round --dry-run      # 유전자대로 꾸민 가짜 출품작 생성
open arena/round-1/gallery.html          # 좋은 순서대로 클릭 → 명령어가 만들어짐
python3 survivor.py vote C A E B D
python3 survivor.py status               # 리더보드 + "당신의 취향을 이기고 있는 유전자"
```
진짜 대결은 `--dry-run`만 빼면 됩니다. 참가자마다 `claude -p`가 자기 폴더에서 `index.html`을 만들어요.
Night Shift 큐에 `survivor.py round`를 넣어 두면 **밤에 경기, 아침에 투표**가 됩니다.

## 규칙
- **유전자 4개:** 스타일(미니멀/맥시멀/레트로 픽셀/브루탈/파스텔/신문) · 작업 속도 · 우선순위 · 시그니처 습관
- **블라인드:** 출품작은 A~E로만 보이고, 순서는 라운드마다 섞여요. 에이전트에게도 페이지에 이름을 쓰지 말라고 지시해요.
- **점수:** 5명이면 1위 4점, 2위 3점… 꼴찌 0점. 완주하지 못한 출품작은 투표와 상관없이 꼴찌로 처리돼요.
- **진화:** 꼴찌 탈락 → 1·2등 교차 + 돌연변이(최소 1개 유전자는 새로) → 새 참가자. 인원은 일정하게 유지돼요.
- **취향 리포트:** 2번 이상 순위가 매겨진 유전자 중 평균 순위가 가장 좋은 3개.
